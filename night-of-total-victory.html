Night of Total Victory 2026

Church / Event Design

Event poster for "Possess Your Possession," a program hosted by First Baptist Church, Olojo-Fagunwa in partnership with the Olojo Fagunwa Indigene in Diaspora Forum, built around a clear thematic message and easy-to-read event information. The event, church name and branding shown belong to First Baptist Church, Olojo-Fagunwa; this project shows the poster design work created for them.

Category
Church / Event Design
Project Type
Commissioned Poster Design

My Role — Graphic Designer

I designed the promotional poster for First Baptist Church, Olojo-Fagunwa. The church, event and content belong to them; my role was the visual design.

Tools Used

CorelDRAW — used to design the poster layout and typography.

Objective

To create a clear, professional promotional graphic for the church's event, communicating the theme, guest speaker and program details at a glance.

Final Design

The completed poster was provided to the church for use in promoting the event.
